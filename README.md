# Cold Email Copy: Grow With Khalaf

An Arabic guide to writing B2B cold emails that get read past the first line: 7 rules (subject, first line, one problem, proof, soft ask, 75–100 words, follow-ups), a full example email, a Claude prompt, and a pre-send checklist. Companion to the [setup guide](https://mohamedkhalafalla.github.io/gwk-cold-email-setup/).

Live page: https://mohamedkhalafalla.github.io/gwk-cold-email-copy/

Examples and numbers are illustrative. Not affiliated with Anthropic.
